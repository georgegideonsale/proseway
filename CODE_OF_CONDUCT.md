# Code of Conduct

Proseway adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) as its code of conduct. The full text is at that link. The short version:

- Be welcoming, patient and kind. People come to this project with different experience, languages and abilities.
- Disagree about ideas, not people. Give and take feedback gracefully.
- Harassment, insults, sexualised language or imagery, publishing someone's private information, and other conduct that would be inappropriate in a professional setting aren't acceptable.

This applies in all project spaces: issues, pull requests, discussions, and anywhere you represent the project.

## Reporting

If someone's behaviour makes you uncomfortable, report it privately to the maintainers:
- through the private "Report a vulnerability / contact maintainers" option on the GitHub repository, or
- by contacting a maintainer directly through their GitHub profile.

Reports are kept confidential. Maintainers will act as described in the Contributor Covenant's enforcement guidelines: correction, warning, temporary ban, or permanent ban, depending on the impact.
